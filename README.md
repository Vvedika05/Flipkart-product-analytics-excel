# Flipkart-product-analytics-excel

This is an end-to-end Excel data analytics project built using a Flipkart-style e-commerce dataset.  
The focus of this project is to demonstrate how raw product data can be transformed into clear, actionable business insights using Excel.

## What I Worked On

- Cleaned and structured **80,000 product records**
- Built a **Product Lookup panel** to simulate a real managerial use-case
- Created **pivot tables** to answer key business questions such as:
  - Which product categories sell the most?
  - Do discounts actually increase sales?
- Designed a **clean and simple dashboard** with KPIs and charts for quick decision-making

---

## Dashboard Highlights

- **KPIs:** Total Products, Average Rating, Average Final Price  
- **Category-wise Sales Performance**  
- **Impact of Discounts on Sales Volume and Pricing**

The dashboard is intentionally kept simple and business-focused to ensure clarity for non-technical stakeholders.

---

## Key Takeaways

- Product sales are relatively balanced across categories, with a few clear leaders.
- Discounted products sell more units on average but at lower final prices, indicating a **volume versus margin trade-off**.
- Excel can serve as an effective **decision-support tool** when analysis and presentation are done thoughtfully.
